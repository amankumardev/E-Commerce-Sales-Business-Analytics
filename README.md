## 📌 Project Overview

This project focuses on analyzing E-Commerce sales data to identify business trends, understand customer purchasing behavior, evaluate product performance, and generate meaningful business insights using Python, SQL, and data visualization.

The analysis helps understand sales performance, profitability, regional trends, and the impact of discounts on business revenue.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Identify top-performing product categories.
- Understand regional sales and profit distribution.
- Analyze monthly sales trends.
- Identify top-selling products and customers.
- Evaluate the impact of discounts on profitability.
- Generate actionable business insights.

## 🔍 Analysis Performed

### 1. Data Cleaning
- Checked missing values.
- Removed duplicate records where applicable.
- Converted order dates into datetime format.
- Prepared data for further analysis.

### 2. Sales Analysis
- Calculated total sales and profit.
- Analyzed category-wise sales.
- Identified top-selling products.
- Evaluated monthly sales performance.

### 3. Regional Analysis
- Compared sales across different regions.
- Analyzed regional profit.
- Identified regions with higher order volumes.

### 4. Customer Analysis
- Identified top customers by sales.
- Analyzed customer purchasing patterns.

### 5. Discount Analysis
- Evaluated the relationship between discounts and profitability.
- Identified discount levels associated with losses.

### 6. SQL Analysis
- Created a sales table using SQLite.
- Calculated business KPIs.
- Performed category-wise and region-wise analysis.
- Analyzed monthly sales and discount performance.

## 📈 Key Business Insights

- Furniture generated the highest sales among all categories.
- Office Supplies achieved the highest profit margin at approximately 16.38%.
- The East region generated the highest total profit.
- August 2025 recorded the highest monthly sales.
- Writing Desk was the top-selling product.
- Higher discounts negatively affected profitability.
- Discounts of 25% and 30% resulted in negative overall profit.

## 🚀 How to Run This Project

1. Clone the repository:


2. Navigate to the project directory:


3. Install the required libraries:

```bash

```

4. Open Jupyter Notebook:

